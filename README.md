# SwiftUI Shader Lab

A small iOS and macOS app for tuning the 41 effects in [SwiftUIShaders](https://github.com/krispuckett/SwiftUIShaders). Choose an effect, adjust its parameters over the included wallpaper, drag the preview for touch-based effects, and copy the modifier call.

Open `SwiftUIShaderLab.xcodeproj` in Xcode and run the `SwiftUIShaderLab` scheme on iOS or macOS. The app includes the upstream Metal shader source and parameter data so the preview uses the same effects and ranges.

The Metal shaders and parameter data are from [krispuckett/SwiftUIShaders](https://github.com/krispuckett/SwiftUIShaders) and retain its MIT license in `LICENSE`.
